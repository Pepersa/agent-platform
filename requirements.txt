# 本机 Python 为 3.13.9（Windows 11 原生）。部分依赖在 3.13 上**尚未提供预编译 wheel**，
# 源码编译可能因缺少 C 工具链/头文件而失败，属于已知现象，不代表代码有问题。
# 典型受影响包：psycopg[binary]、langgraph-checkpoint-postgres（依赖 psycopg）、
#               部分向量/检索类扩展。
#
# 因此本项目代码对所有可选依赖做 **懒加载 / try-import 降级**：
#   · 缺 langgraph          → orchestration.graph.build_graph 抛出明确中文错误
#   · 缺 langgraph-checkpoint-postgres → 自动降级为 MemorySaver（内存 checkpoint）
#   · 缺 psycopg            → 审计自动降级为本地 SQLite，再降级为 JSONL
#   · 缺 sqlglot            → sql_query 退化为正则保守只读校验
#   · 缺 pyyaml             → 路由表回退到代码内常量 DEFAULT_ROUTES
#   · 缺 openai             → LLMClient 抛出明确中文错误
#   · 缺 fastapi/uvicorn    → api.app 无法启动（接入层是唯一硬依赖）
#
# 最小可跑集合（冒烟测试除真实 LLM 外的全部用例）：
#   fastapi, uvicorn, openai, langgraph, pydantic
# ============================================================================
